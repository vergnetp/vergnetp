### Philippe Vergnet

Full-stack engineer — comfortable across the whole stack, from the maths up to the deploy infrastructure.

**About these repositories.** They're personal projects, built solo in my spare time — a fair amount of it at night. They're working **MVPs / prototypes**, not products with real users, so you won't find test suites, CI, or production hardening here; that wasn't the point. What they *do* show is how I design systems and the range I work across — and all of it is hand-written, from before AI coding assistants existed.

#### ⭐ Pick of the bunch

- 🌐 **[digitalpixo](https://github.com/vergnetp/digitalpixo)** — the most complete one. A full-stack SaaS that translates the text *inside* images and documents while preserving layout and fonts (OCR → translate → re-render). Hand-rolled Python framework — DB abstraction, encryption, Stripe, image/OCR — behind a Next.js app. *(2024)*

- 🧠 **[neural-network-paper](https://github.com/vergnetp/neural-network-paper)** + ⚙️ **[neural-network](https://github.com/vergnetp/neural-network)** — the one I'm most proud of intellectually: backpropagation **derived from first principles** in matrix form (the paper), then **implemented in C#** with GPU-accelerated matrix ops via CUDA/OpenCL, plus boosting, ensembles and cross-validation (the code). The maths and the engine, side by side. *(2016)*
